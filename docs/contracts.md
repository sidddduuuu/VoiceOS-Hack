# Frozen integration contracts

All ticket branches start from this foundation. Do not edit this file,
`src/labloop/contracts.py`, or `pyproject.toml` inside a ticket branch.

## Module APIs

### `labloop.protocols`

```python
load_protocol(path: str | Path) -> Protocol
load_protocols(directory: str | Path) -> dict[str, Protocol]
current_step(protocol: Protocol, run: ExperimentRun) -> ProtocolStep
advance_run(protocol: Protocol, run: ExperimentRun, completed_step_id: str) -> ExperimentRun
start_run(run: ExperimentRun, started_at: str) -> ExperimentRun
complete_run(protocol: Protocol, run: ExperimentRun, completed_at: str) -> ExperimentRun
```

Functions are pure and return new immutable values. Invalid protocol JSON,
unknown steps, illegal transitions, and attempts to advance completed runs raise
`ValueError` with actionable messages.

### `labloop.storage`

```python
class EventStore:
    def __init__(self, path: str | Path): ...
    def save_run(self, run: ExperimentRun) -> None: ...
    def get_run(self, run_id: str) -> ExperimentRun | None: ...
    def list_runs(self) -> list[ExperimentRun]: ...
    def append(self, run_id: str, kind: EventKind, payload: dict,
               supersedes_event_id: str | None = None) -> AuditEvent: ...
    def list_events(self, run_id: str) -> list[AuditEvent]: ...
```

All writes use SQLite transactions. Events are append-only; no public update or
delete operation exists.

### `labloop.validation`

```python
validate_measurement(step: ProtocolStep, measurement: Measurement) -> list[ValidationIssue]
```

Return one issue per missing required field plus a warning when a numeric value is
outside `expected_range`. Validation never mutates or diagnoses.

### `labloop.service`

```python
class LabLoopService:
    def __init__(self, db_path: str | Path, protocol_dir: str | Path): ...
    def begin_experiment(self, protocol_id: str, operator: str,
                         sample_ids: list[str], started_at: str | None = None) -> ExperimentRun: ...
    def get_run(self, run_id: str) -> ExperimentRun: ...
    def get_current_step(self, run_id: str) -> ProtocolStep: ...
    def record_observation(self, run_id: str, note: str,
                           sample_id: str | None = None) -> AuditEvent: ...
    def record_measurement(self, measurement: Measurement) -> tuple[AuditEvent, list[ValidationIssue]]: ...
    def complete_checkpoint(self, run_id: str, step_id: str) -> ExperimentRun: ...
    def correct_event(self, run_id: str, event_id: str, replacement: dict) -> AuditEvent: ...
    def finish_experiment(self, run_id: str, completed_at: str | None = None) -> ExperimentRun: ...
```

The service composes protocol, storage, and validation modules. It does not send
Slack messages, speak, or mutate inventory.

### `labloop.inventory`

```python
class InventoryStore:
    def __init__(self, path: str | Path): ...
    def upsert_item(self, item: InventoryItem) -> None: ...
    def get_item(self, item_id: str) -> InventoryItem | None: ...
    def list_items(self) -> list[InventoryItem]: ...
    def consume(self, item_id: str, amount: float, unit: str) -> tuple[InventoryItem, PurchaseRequest | None]: ...
    def list_purchase_requests(self, status: str | None = None) -> list[PurchaseRequest]: ...
```

Reject non-positive usage, unit mismatch, and negative resulting inventory. A
threshold crossing creates one pending request; repeated usage must not duplicate it.

### `labloop.supervisor`

```python
class SlackGateway:
    def __init__(self, token: str, channel: str): ...
    def send_question(self, run_id: str, context: dict, question: str) -> SupervisorMessage: ...
    def fetch_replies(self, run_id: str, thread_id: str) -> list[SupervisorMessage]: ...
```

Use Slack Web API through the standard library. Validate HTTP status, Slack's
`ok` field, response shapes, token presence, and timeouts. Never log the token.

### `labloop.audio`

```python
speak(text: str) -> None
trigger_voiceos(keycode: int, modifiers: tuple[str, ...]) -> None
```

On non-macOS systems, raise `RuntimeError`. Speech uses `/usr/bin/say`. The wake
bridge executable recognizes the exact phrase `Hey Jarvis` and invokes the
configured VoiceOS shortcut; it does not interpret laboratory speech itself.

### `labloop.mcp_server`

```python
build_server(db_path: str | Path, protocol_dir: str | Path) -> FastMCP
main() -> None
```

Expose the exact tool names defined in ticket 08. Tool handlers validate boundary
inputs, call service modules, and return short text suitable for VoiceOS.

### `labloop.dashboard`

```python
main() -> None
```

Serve `web/` and read-only JSON endpoints with the standard library. Bind to
`127.0.0.1`; no write endpoints. One-second browser polling is sufficient.

## Time and identifiers

- Timestamps are UTC ISO-8601 strings ending in `Z`.
- New identifiers use `uuid.uuid4()` strings.
- Stored JSON uses enum values, not enum names.
- Public functions reject empty identifiers and non-finite numeric measurements.
